# Audits

Esta carpeta almacena auditorías del proyecto (seguridad, producto, scope,
accesibilidad) a medida que se realizan, una por archivo, con fecha y fase
en el nombre.

Convención de nombre: `YYYY-MM-DD-<fase>-<tipo>.md` (por ejemplo,
`2026-09-27-0.1-self-audit.md`).

La primera auditoría de este proyecto (autoauditoría de cierre de 0.1) se
reporta directamente en el mensaje de entrega de la sesión que la realizó;
se copia aquí cuando el proceso de auditoría se formalice (0.9 — Hardening).
